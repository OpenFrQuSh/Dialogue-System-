# Unity UGUI 分支对话系统设计规格

## 1. 目标

为 Unity `2022.3.62f1c1` 工程实现一套可复用的 UGUI 对话系统插件。视觉参考《明日方舟》对话界面的信息布局与黑白科技氛围，但所有界面图形均为原创占位素材，不复制角色、Logo 或原始美术资源。

首版支持：

- ScriptableObject 对话资产与自定义 Inspector。
- 逐字显示、点击补全和逐句推进。
- 自动播放以及 `1× / 2× / 4×` 倍速。
- 跳过至下一个玩家选项或结局。
- 本次流程的已播放台词与玩家选择历史。
- 布尔值/整数条件、变量效果、分支选项和多结局。
- 响应式 UGUI 演示界面、中文示例剧情和自动化测试。

首版不包含角色立绘切换、语音、存档读档、本地化管线、可视化节点图编辑器或外部 JSON 导入。

## 2. 技术约束

- Unity：`2022.3.62f1c1`。
- UI：UGUI `1.0.0` 与 TextMeshPro `3.0.7`。
- 不添加额外运行时第三方依赖。
- 运行时代码与编辑器代码使用独立程序集定义。
- 插件根目录为 `Assets/DialogueSystem/`。
- 新增代码、复杂逻辑、空值保护和编辑器/运行时分支必须在上方用中文注释说明原因与意图。

## 3. 架构

系统采用“数据资产—无界面运行器—UGUI 视图”三层结构：

1. `DialogueAsset` 只保存剧情数据，不依赖场景对象。
2. `DialogueRunner` 读取资产、管理变量并推进节点，通过事件发布当前状态。
3. `DialogueView` 订阅运行器事件，负责动画、输入、按钮、选项和历史面板。

运行器不直接引用具体 TextMeshPro、Button 或 Animator 组件。UI 可以替换而不改变剧情执行逻辑，运行器也可以在 EditMode 中独立测试。

## 4. 数据模型

### 4.1 DialogueAsset

每个资产包含：

- 资产显示名称。
- 入口节点 GUID。
- 变量初始值列表。
- 节点列表。

加载时建立 `GUID → 节点` 字典。节点在 Inspector 中重新排序不会改变连接关系。

### 4.2 节点类型

`Line` 台词节点：

- 角色名。
- 正文。
- 下一节点 GUID。

`Choice` 选项节点：

- 可选提示文本。
- 一个或多个选项。
- 每个选项包含显示文本、可见条件、变量效果和下一节点 GUID。

`End` 结局节点：

- 稳定的结局标识。
- 可选结局说明。

### 4.3 变量、条件和效果

首版变量只允许布尔值与整数。变量名称在同一资产内唯一。

条件支持：

- 布尔值等于预期值。
- 整数等于、不等于、大于、大于等于、小于、小于等于目标值。

同一选项的多个条件使用“全部满足”语义。效果支持设置布尔值、设置整数以及对整数加减固定值。效果在玩家确认选项后、进入下一节点前执行。

## 5. 运行流程

1. `StartDialogue` 校验资产并复制初始变量，清空会话历史。
2. 运行器从入口 GUID 取得节点并发布对应事件。
3. 台词节点显示完成后，由玩家输入或自动模式推进。
4. 选项节点过滤不可用选项，暂停自动模式的推进计时，等待玩家选择。
5. 选择结果写入历史，应用变量效果并跳转。
6. 结局节点发布结局事件并结束会话。

为了防止坏数据锁死游戏，单次同步推进设置最大节点步数保护。重复 GUID、缺失入口、断链、没有可用选项或未知变量都会停止推进，并输出包含资产名和节点 GUID 的错误。

## 6. UGUI 与交互

### 6.1 布局

- `CanvasScaler` 使用 `Scale With Screen Size`，参考分辨率为 `1920×1080`。
- 全屏背景使用原创黑灰渐变与几何科技线条。
- 底部约 25% 为透明渐变字幕区，左侧显示角色名，右侧显示正文。
- 左上为“记录”按钮；右上依次为倍速、自动和跳过按钮。
- 分支选项显示在右下区域，采用竖向黑白按钮。
- 跳过确认框和历史面板位于独立遮罩层，避免点击穿透。

布局需在 `16:9`、`16:10` 和超宽比例下保持主要按钮、名字、正文和选项在安全区域内。

### 6.2 打字与推进

- 正文按照可配置的基础字符速率逐字显示。
- 文本尚未显示完时点击正文区域，立即补全当前句。
- 文本已经显示完时再次点击，进入下一节点。
- 打字状态、等待推进状态和选择状态互斥，避免一次点击跨过两句。

### 6.3 自动与倍速

- 自动模式在整句显示完成后等待“基础延迟 + 按文本长度计算的延迟”，再推进。
- 遇到选择节点时停止自动推进，玩家选择后继续保持原自动开关状态。
- 倍速按钮循环 `1× → 2× → 4×`，同时缩短字符间隔和自动等待时间。

### 6.4 跳过

- 点击跳过按钮先显示确认框，防止误触。
- 确认后无动画地遍历连续台词节点，记录经过的台词，并在下一个选择节点或结局节点停止。
- 跳过不会自动替玩家选择分支。
- 跳过过程中仍执行节点合法性与最大步数保护。

### 6.5 历史

- 历史只包含本次会话实际经过的台词与玩家选择，不展示未进入的分支。
- 打开历史面板时暂停打字和自动推进计时；关闭后从原状态继续。
- 历史使用可滚动列表，并自动定位到最新记录。

## 7. 内容编辑

通过 `Create → Dialogue System → Dialogue Asset` 创建剧情资产。自定义 Inspector 使用节点卡片，不实现节点图：

- 新增、复制和删除台词、选择、结局节点。
- 自动生成稳定 GUID。
- 使用节点下拉框选择入口和跳转目标，界面同时显示简短 GUID 便于排错。
- 编辑变量、条件和效果。
- 提供“校验剧情”按钮，报告重复 GUID、缺失入口、断链、无可用出口、未使用变量和不可达节点。

删除仍被引用的节点时必须显示确认信息和引用位置，不静默破坏已有内容。

## 9. MCP for Unity 接入

- 安装 CoplayDev `MCP for Unity v10.0.0`：
  `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#v10.0.0`
- 在 Unity 的 `Window → MCP for Unity` 面板安装服务器依赖并启动桥接。
- Windows 上为 Codex 配置 stdio 传输，由插件更新用户级 `~/.codex/config.toml`。
- Codex 无法热加载 MCP 配置时，重启 Codex 后继续本任务。
- 连接后先执行读取场景和读取 Console 的无副作用探针，再使用 MCP 创建或修改演示场景。

## 10. 测试与验收

EditMode 测试：

- GUID 索引、重复与断链校验。
- 布尔值和整数条件判断。
- 变量效果应用。
- 台词、选择和结局跳转。
- 不可达节点与没有可用选项的错误处理。

PlayMode 测试：

- 打字机播放与点击补全。
- 第二次点击推进且不会跨过两句。
- 自动模式暂停、恢复和选项停靠。
- `1× / 2× / 4×` 速度切换。
- 跳过在选择或结局处停止。
- 历史面板内容、滚动和暂停行为。

最终验收条件：

- Unity Console 无编译错误。
- 所有 EditMode 与 PlayMode 测试通过。
- MCP 状态显示已连接，Codex 能调用 Unity 场景与 Console 工具。
- 示例场景可从入口完成至少两个不同结局。
- 三种目标屏幕比例下无遮挡、溢出或不可点击控件。
- 项目停止播放后不遗留场景脏状态或临时对象。
