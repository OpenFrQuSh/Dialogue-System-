# Dialogue System Chinese Font

`NotoSansSC-Variable.ttf` is Noto Sans SC from the official Google Fonts repository:

https://github.com/google/fonts/tree/main/ofl/notosanssc

The font is distributed under the SIL Open Font License. Keep `OFL.txt` with the font when redistributing this plugin.

`NotoSansSC-Dynamic.asset` is generated by `DialogueTourSampleBuilder` as a dynamic, multi-atlas TextMeshPro font asset. The builder prewarms all characters used by the samples and persists the material and atlas as sub-assets.
